Backup & restore

All members, receipts, expenses with bill photos, tasks, contacts and documents are saved on this phone only. Save a backup file to JioCloud after every few entries, so nothing is lost if the phone is changed, reset or the browser data is cleared.

How to keep the backup in JioCloud

  1. Press Save backup to JioCloud. Your phone's share menu opens.
  2. Choose JioCloud (JioAICloud) from the list. It uploads the file. If JioCloud is not listed, press Download backup file instead and upload that file from the JioCloud app.
  3. To restore on a new phone: download the latest backup file from JioCloud, open this app, press Restore from backup and pick the file.

Online sharing: committee & members

Right now everything is saved on this phone only. Connect a free Google Firebase database so that 3 committee members can enter data, one admin can edit, and every member can view reports and post complaints from their own phone. Do this once, on the admin's phone.

  1. On a computer, open console.firebase.google.com and sign in with the society's or your Gmail. Tap Create a project, name it stuti-avenue, turn Google Analytics off, and create it.
  2. Build → Authentication → Get started → Google: turn it on, choose your email as support email, Save. Then Settings → Authorized domains → Add domain and add this app's address:
  3. Build → Firestore Database → Create database: choose location asia-south1 (Mumbai), start in production mode.
  4. Enter the admin's Gmail below and tap Copy security rules. In Firestore open the Rules tab, delete what is there, paste, and tap Publish.
  5. Project settings (gear) → Your apps → Web </>: register an app named Stuti Avenue. Copy the whole firebaseConfig block it shows and paste it below.
  6. Tap Connect & sign in, sign in with the admin Gmail, and upload this phone's records when asked.

Stop using online sharing on this phone

This phone goes back to its own offline records. Nothing online is deleted.
